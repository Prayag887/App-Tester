# Governance

App Tester is currently maintained by the repository owner and approved
maintainers.

Maintainers decide on releases, supported platforms, security responses, and
breaking changes. Decisions favor user privacy, safety, maintainability, and
clear documented behavior. Significant design changes should be discussed in an
issue or discussion before implementation.

The project follows semantic versioning where practical. A release requires a
reviewed pull request, passing required checks, completed release checklist,
and release notes covering behavior changes and known limitations.
