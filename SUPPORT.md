# Support

- **Usage questions and ideas:** start a GitHub Discussion when Discussions are
  enabled, or open a feature request using the issue form.
- **Reproducible defects:** use the bug report form and redact all traffic,
  tokens, certificates, and device identifiers.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post
  them in public issues or discussions.

App Tester is maintained on a best-effort basis. Include the desktop version,
operating system, Android version, connection type, and sanitized logs when
requesting help.
